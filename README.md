# منصة جمعية لبيك الخيرية

موقع عائلي خاص لأفراد جمعية "لبيك" لإدارة كشوف النقاط الدراسية للأبناء
وترتيبهم سنوياً تحضيراً للتكريم.

## المكوّنات التقنية

- **Next.js 14** (App Router, JavaScript)
- **Supabase**: قاعدة بيانات Postgres + المصادقة (Auth) + تخزين الصور (Storage)
- **Tailwind CSS** للتنسيق
- **Tesseract.js** لاستخراج المعدل تلقائياً من صورة كشف النقاط (مجاني/يعمل في المتصفح)

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم املأ القيم من مشروع Supabase الخاص بك
npm run dev
```

افتح http://localhost:3000

## إعداد قاعدة البيانات

نفّذ محتوى الملف `supabase/schema.sql` كاملاً مرة واحدة داخل
Supabase SQL Editor. ينشئ الجداول، دوال الصلاحيات (RLS)، وحاوية تخزين
الصور `report-cards`.

بعدها نفّذ `supabase/migration_002_features.sql` (مرة واحدة أيضاً) لإضافة:
أرشيف السنوات الدراسية القابل للتنقل، إعدادات الموقع (الشعار واسم
الجمعية)، قوالب شهادات التكريم، وحاوية تخزين عامة `site-assets`. آمن
التنفيذ على موقع منشور فعلياً — لا يمسّ أي بيانات موجودة.

ثم نفّذ `supabase/migration_003_theme.sql` لإضافة إمكانية تخصيص ألوان
الموقع من صفحة الإعدادات. آمن التنفيذ أيضاً.

وأخيراً نفّذ `supabase/migration_004_auto_link_profile.sql` — يضيف trigger
يربط أي حساب مشرف فرعي جديد بمن دعاه تلقائياً وبشكل مضمون على مستوى قاعدة
البيانات (حل جذري بدل الاعتماد فقط على كود الواجهة)، ويصلح تلقائياً أي
حسابات غير مرتبطة موجودة حالياً بربطها بالمشرف العام.

بعد إنشاء أول حساب (المشرف العام / لجنة الجمعية)، رقّه يدوياً بتنفيذ:

```sql
update public.profiles set role = 'super_admin'
where id = (select id from auth.users where email = 'admin@example.com');
```

## النشر

راجع دليل النشر المرفق (PDF/الرابط المرسل) للحصول على خطوات تفصيلية
لإنشاء حساب Supabase و Vercel ونشر الموقع فعلياً.

## هيكل الأدوار

- **مشرف عام (super_admin)**: يرى كل العائلات، ويصل للوحة الترتيب والتكريم.
- **مشرف عائلة (supervisor)**: يضيف أبناءه/إخوته ويرفع كشوف نقاطهم. يمكنه
  دعوة ابنه الأكبر ليصبح مشرفاً فرعياً (حساب مستقل) عبر رابط دعوة من صفحة
  "دعوة مشرف فرعي" — عندها يبقى يرى بيانات أبناء ابنه أيضاً (هرم متعدد
  المستويات).

## تسريع وتخفيف الموقع (v5)

- **تجميع الاستعلامات المستقلة**: كل صفحة كانت تنتظر كل استعلام قاعدة
  بيانات بالتتابع (واحداً تلو الآخر) أصبحت الآن تُطلق الاستعلامات
  المستقلة عن بعضها دفعة واحدة (`Promise.all`)، مما يقلّص زمن تحميل
  الصفحات ذات الاستعلامات المتعددة (لوحة التحكم، عائلتي، لوحة الترتيب،
  ملف كل فرد، تصدير CSV، الإعدادات، الشهادات) بشكل ملحوظ.
- **إلغاء تكرار الطلبات (caching) داخل نفس الطلب**: البيانات المشتركة
  بين عدة أجزاء من نفس الصفحة (الملف الشخصي، إعدادات الموقع، السنة
  الدراسية، قائمة العائلة) أصبحت تُجلب مرة واحدة فقط لكل طلب صفحة بدل
  إعادة الجلب من قاعدة البيانات في كل مكان يُستخدم فيه.
- **تحسين الصور**: شعار الجمعية (يظهر تقريباً في كل صفحة) أصبح يُعرض عبر
  مكوّن الصور المُحسَّن في Next.js بدل وسم `<img>` العادي، فيُصغَّر
  ويُضغط تلقائياً حسب حجم الشاشة بدل تحميل الصورة الأصلية كاملة في كل
  مرة.
- لا حاجة لأي تحديث في قاعدة البيانات (SQL) لهذا التحديث — تغييرات في
  كود التطبيق فقط، تُطبَّق بمجرد رفع الكود الجديد إلى GitHub (يعيد
  Vercel النشر تلقائياً).

## إصلاحات موثوقية (v4)

- **ربط تلقائي مضمون لحسابات الدعوة**: trigger على قاعدة البيانات ينشئ
  ويربط حساب أي مشرف فرعي جديد بمن دعاه لحظة إنشاء الحساب، بغض النظر عن أي
  عطل محتمل في رابط الدعوة أو كود الواجهة.
- **بطاقة "حسابات غير مرتبطة"** في صفحة الإعدادات (تظهر فقط عند الحاجة):
  تتيح للمشرف العام ربط أي حساب يتيم بضغطة واحدة دون أوامر SQL يدوية.

## إعادة التصميم (v3)

- **هوية بصرية جديدة**: ألوان دافئة (كريمي/كهرماني/مرجاني) بدل الأخضر
  السابق، بطاقات دائرية الحواف، وبطاقة ترحيب داكنة في الصفحة الرئيسية
  للوحة التحكم.
- **ألوان قابلة للتعديل**: من صفحة الإعدادات، أربعة ألوان رئيسية (خلفية
  الصفحة، العناوين، اللون الأساسي، لون التمييز) قابلة للتغيير مباشرة عبر
  متغيرات CSS، مع زر لاستعادة الألوان الافتراضية.
- **قائمة تنقّل جديدة**: شريط جانبي بأيقونات دائرية على الشاشات الكبيرة،
  وشريط سفلي عائم على الهاتف، بدل القائمة الأفقية العلوية السابقة.

## الميزات المضافة (v2)

- **بحث فوري** في صفحة "عائلتي" ولوحة المشرف العام.
- **إعدادات الموقع** (`/dashboard/admin/settings`، للمشرف العام فقط): رفع
  شعار الجمعية، تعديل اسمها، وإضافة/تفعيل سنوات دراسية جديدة.
- **أرشيف سنوات دراسية**: قائمة اختيار السنة تظهر في كل صفحة تعرض بيانات
  دراسية، وتتيح العودة لأي سنة سابقة دون فقدان بيانات السنة الحالية.
- **سهم رجوع** في كل صفحة داخلية، مهيّأ خصيصاً لسهولة الاستعمال على الهاتف.
- **محرر شهادات التكريم** (`/dashboard/admin/certificates`): تصميم كامل
  لشكل الشهادة (الخلفية، النصوص، الشعار) بالسحب والإفلات، مع متغيرات
  ديناميكية مثل اسم الطالب والمعدل والترتيب.
- **طباعة الشهادات**: من لوحة الترتيب، زر "شهادة" بجانب كل طالب يفتح
  نسخة جاهزة للطباعة (أو الحفظ كـ PDF عبر خاصية الطباعة في المتصفح).

## ملاحظات مهمّة حول هذه النسخة (v1)

- **قصّ الصورة**: تحديد يدوي بالسحب على الصورة (وليس اكتشاف حواف تلقائي
  بالكامل كـ CamScanner). يمكن تطويره لاحقاً بمكتبة اكتشاف حواف مخصّصة.
- **قراءة المعدل تلقائياً (OCR)**: تعتمد على مكتبة مجانية تعمل داخل
  المتصفح، دقتها محدودة خصوصاً مع الخط اليدوي أو الصور غير الواضحة، لذلك
  تبقى دائماً قابلة للتعديل يدوياً من طرف المشرف قبل الحفظ النهائي.
- لم يُختبر تشغيل المشروع فعلياً (`npm install` / `npm run build`) داخل
  بيئة العمل التي كُتب فيها الكود بسبب قيود شبكة على تلك البيئة تحديداً؛
  تم فحص الصيغة البرمجية لجميع الملفات آلياً للتأكد من خلوها من أخطاء
  syntax، لكن يُنصح بتجربة `npm run dev` محلياً أو مراقبة سجل البناء في
  Vercel عند أول نشر، ومراسلتي بأي خطأ يظهر لإصلاحه.
