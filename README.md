# منصة جمعية لبيك الخيرية

موقع عائلي خاص لأفراد جمعية "لبيك" لإدارة كشوف النقاط الدراسية للأبناء
وترتيبهم سنوياً تحضيراً للتكريم.

## المكوّنات التقنية

- **Next.js 14** (App Router, JavaScript)
- **Supabase**: قاعدة بيانات Postgres + المصادقة (Auth) + تخزين الصور (Storage)
- **Tailwind CSS** للتنسيق
- **Tesseract.js** لاستخراج المعدل تلقائياً من صورة كشف النقاط (مجاني/يعمل في المتصفح)

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم املأ القيم من مشروع Supabase الخاص بك
npm run dev
```

افتح http://localhost:3000

## إعداد قاعدة البيانات

نفّذ محتوى الملف `supabase/schema.sql` كاملاً مرة واحدة داخل
Supabase SQL Editor. ينشئ الجداول، دوال الصلاحيات (RLS)، وحاوية تخزين
الصور `report-cards`.

بعد إنشاء أول حساب (المشرف العام / لجنة الجمعية)، رقّه يدوياً بتنفيذ:

```sql
update public.profiles set role = 'super_admin'
where id = (select id from auth.users where email = 'admin@example.com');
```

## النشر

راجع دليل النشر المرفق (PDF/الرابط المرسل) للحصول على خطوات تفصيلية
لإنشاء حساب Supabase و Vercel ونشر الموقع فعلياً.

## هيكل الأدوار

- **مشرف عام (super_admin)**: يرى كل العائلات، ويصل للوحة الترتيب والتكريم.
- **مشرف عائلة (supervisor)**: يضيف أبناءه/إخوته ويرفع كشوف نقاطهم. يمكنه
  دعوة ابنه الأكبر ليصبح مشرفاً فرعياً (حساب مستقل) عبر رابط دعوة من صفحة
  "دعوة مشرف فرعي" — عندها يبقى يرى بيانات أبناء ابنه أيضاً (هرم متعدد
  المستويات).

## ملاحظات مهمّة حول هذه النسخة (v1)

- **قصّ الصورة**: تحديد يدوي بالسحب على الصورة (وليس اكتشاف حواف تلقائي
  بالكامل كـ CamScanner). يمكن تطويره لاحقاً بمكتبة اكتشاف حواف مخصّصة.
- **قراءة المعدل تلقائياً (OCR)**: تعتمد على مكتبة مجانية تعمل داخل
  المتصفح، دقتها محدودة خصوصاً مع الخط اليدوي أو الصور غير الواضحة، لذلك
  تبقى دائماً قابلة للتعديل يدوياً من طرف المشرف قبل الحفظ النهائي.
- لم يُختبر تشغيل المشروع فعلياً (`npm install` / `npm run build`) داخل
  بيئة العمل التي كُتب فيها الكود بسبب قيود شبكة على تلك البيئة تحديداً؛
  تم فحص الصيغة البرمجية لجميع الملفات آلياً للتأكد من خلوها من أخطاء
  syntax، لكن يُنصح بتجربة `npm run dev` محلياً أو مراقبة سجل البناء في
  Vercel عند أول نشر، ومراسلتي بأي خطأ يظهر لإصلاحه.
